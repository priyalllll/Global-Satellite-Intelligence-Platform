# Project Objectives

## Main Objective

Develop an end-to-end data analytics platform that enables users to explore, analyze, and visualize the global satellite ecosystem through structured data processing, interactive dashboards, and business intelligence techniques.

---

## Business Objectives

- Analyze global satellite launch trends over time.
- Compare satellite ownership across different countries.
- Evaluate satellite operators and mission categories.
- Understand orbital distribution and utilization.
- Identify long-term growth patterns within the global satellite industry.
- Present insights through interactive dashboards.
- Support data-driven research and strategic analysis.

---

## Technical Objectives

- Collect publicly available satellite datasets.
- Clean and preprocess raw satellite data.
- Design a relational PostgreSQL database.
- Perform SQL-based analytical queries.
- Conduct Exploratory Data Analysis (EDA) using Python.
- Develop interactive Power BI dashboards.
- Generate analytical reports and business insights.
- Maintain professional documentation and version control using Git and GitHub.
