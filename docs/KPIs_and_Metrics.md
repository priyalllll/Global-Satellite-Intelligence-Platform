# KPIs and Metrics

## Key Performance Indicators (KPIs)

| KPI | Description | Business Value |
|------|-------------|----------------|
| Total Satellites | Total number of satellites in the dataset | Shows the size of the satellite ecosystem |
| Active Satellites | Number of operational satellites | Indicates current operational capacity |
| Countries Participating | Number of countries owning or operating satellites | Reflects global participation |
| Satellite Operators | Total number of satellite operators | Measures industry diversity |
| Total Launches | Total recorded satellite launches | Indicates overall launch activity |
| Most Active Country | Country with the highest number of satellites | Identifies leading space nations |
| Most Common Orbit | Orbit containing the highest number of satellites | Highlights orbital utilization |
| Most Common Mission Type | Most frequently occurring satellite mission | Shows dominant satellite applications |

---

## Analytical Metrics

| Metric | Business Question |
|---------|-------------------|
| Satellites launched per year | Is the satellite industry growing? |
| Country-wise satellite distribution | Which countries dominate satellite operations? |
| Operator-wise satellite distribution | Which organizations own the most satellites? |
| Orbit distribution | Which orbit is used most frequently? |
| Mission category distribution | Which satellite missions are most common? |
| Launch vehicle analysis | Which launch vehicles are used most often? |
| Annual satellite growth rate | How fast is the satellite industry expanding? |
| Average satellite lifespan (if available) | How long do satellites remain operational? |

---

## KPI Dashboard Strategy

The dashboard will present high-level KPIs at the top, followed by detailed visualizations and interactive filters that allow users to explore trends, compare entities, and answer key business questions.
