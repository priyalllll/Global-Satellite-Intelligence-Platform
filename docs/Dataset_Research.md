# Dataset Research

## Objective

The purpose of this research is to identify publicly available satellite datasets that can support the objectives of the Global Satellite Intelligence Platform (GSIP). The datasets will be evaluated based on reliability, completeness, accessibility, documentation, and relevance to the project's analytical goals.

---

## Data Requirements

| Information Needed | Required | Purpose |
|--------------------|----------|---------|
| Satellite Name | Yes | Identification |
| Country | Yes | Country analysis |
| Operator | Yes | Operator analysis |
| Launch Date | Yes | Trend analysis |
| Orbit Type | Yes | Orbit analysis |
| Mission Type | Yes | Mission analysis |
| Operational Status | Yes | Active vs inactive analysis |
| Launch Vehicle | Preferred | Additional insights |

## Selection Criteria

The final dataset will be selected based on:

- Reliability of the source
- Data completeness
- Data quality
- Availability of documentation
- Relevance to project objectives
- Ease of use
