# Project Scope

## In Scope

### Data Management
- Collect publicly available satellite datasets.
- Clean and preprocess raw satellite data.
- Store processed data in PostgreSQL.

### Data Analytics
- Perform SQL-based analytical queries.
- Conduct Exploratory Data Analysis (EDA) using Python.
- Generate business insights and KPIs.

### Business Intelligence
- Develop interactive Power BI dashboards.
- Create visualizations for satellite launches, countries, operators, missions, and orbital analysis.
- Enable dashboard filtering and comparative analysis.

### Documentation
- Maintain project documentation.
- Create a data dictionary.
- Document SQL queries and analytical workflow.
- Publish the project on GitHub.

---

## Out of Scope

The first version of GSIP will **not** include:

- Live satellite tracking
- Real-time data integration
- Machine Learning or predictive analytics
- AI-powered recommendations
- Mobile application
- User authentication and login
- Cloud deployment
- Satellite communication or control systems
- 3D visualization and simulation

---

## Functional Scope

- Import and manage satellite datasets.
- Perform SQL-based analysis.
- Generate KPIs and analytical reports.
- Build interactive Power BI dashboards.
- Present business insights through visualizations.

---

## Non-Functional Scope

- Ensure clean and reliable data.
- Maintain an organized project structure.
- Provide user-friendly dashboards.
- Ensure reproducible analytics workflows.
- Maintain clear and professional documentation.
