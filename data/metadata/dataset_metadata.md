## Dataset Purpose

This dataset serves as the primary data source for the Global Satellite Intelligence Platform (GSIP). It contains information about operational satellites, including ownership, launch details, mission categories, orbital characteristics, and technical specifications.

The dataset will be used for:

- SQL Analytics
- Exploratory Data Analysis (EDA)
- KPI Generation
- Power BI Dashboard Development
- Business Insight Generation

---

## Expected Analysis Areas

- Satellite launch trends
- Country-wise satellite distribution
- Operator analysis
- Mission type analysis
- Orbit classification
- Operational status analysis
- Launch vehicle analysis (if available)
